# Материалы для РПЗ и защиты

Основные учебные источники: приложенные README курса и React, лекции 8 и 9.
Их требования сопоставлены с реализацией в [requirements.md](requirements.md).

Предметные препринты, использованные в РПЗ:

1. Algama и соавт. **Residential Electricity Consumption Dataset for Sri Lanka
   (RECON-SL)**, 2026: https://arxiv.org/abs/2609.28783.
   PDF для печати: https://arxiv.org/pdf/2609.28783.
2. Kale, Apte, Gosavi. **Stochastic Mixed-Integer Optimization of Dynamic
   Electricity Tariffs with Consumer Protection**, 2026:
   https://arxiv.org/abs/2608.12688.

Это внешние исследовательские источники, а не функциональность прототипа.
Система не прогнозирует потребление и не оптимизирует тарифы.

Если преподаватель требует бумажную работу с источником, откройте PDF первого
препринта, распечатайте и подпишите перевод терминов вручную. Электронная
подготовка РПЗ не заменяет этот пункт.

| Термин | Перевод |
|---|---|
| household | домохозяйство |
| electricity consumption | потребление электроэнергии |
| smart meter | интеллектуальный счётчик |
| tariff | тариф |
| consumer protection | защита потребителя |
| utility bill | счёт за коммунальные услуги |

Технические источники и ссылки приведены в списке литературы РПЗ.

Для ответа о Babel учитывайте версию сборщика: этот проект использует Vite 8
и plugin-react 6 с Oxc и Rolldown; отдельного Babel в зависимостях нет.
