# Проверка ЛР-5

Дата: 10.11.2026. Проверены TypeScript/Vite, Vitest и сценарии в Chrome.
Приложение проверено без создания пользовательских скриншотов.

- Сборка: `npm run build`.
- Чистая установка по lock-файлу: `npm ci` прошла; затем повторно прошли
  сборка, тесты и все сценарии браузера.
- Модульные проверки: `npm test` — 3 теста: фильтрация/сброс, пустая
  коллекция, последовательность и циклический переход.
- 19 проверок браузера: шесть карточек; загрузка всех изображений;
  изображение и воспроизводимое видео по умолчанию; два отключённых пункта
  меню; отложенное применение ползунка; фильтр 10; переход внутри результата
  и по кругу; сохранение фильтра между страницами; пустой результат;
  сброс; заголовки вкладок; неверный id; fallback при ошибке изображения;
  отсутствие API-вызовов; отсутствие переполнения на 320 px; отсутствие
  необработанных ошибок JavaScript.

Состояние задания, которое должен завершить студент: вписать ФИО и группу,
сделать и вставить девять снимков по screenshots.md, добавить два снимка в РПЗ
и обновить его содержание после вставки. Бумажный препринт — по указанию
преподавателя; ссылки и термины находятся в sources.md.

## Файлы

- `report-lab5.docx` — отчёт с девятью пронумерованными местами для снимков.
- `rpz-lab5.docx` — РПЗ по состоянию на ЛР-5 с ТЗ и таблицей HTTP-методов.
- `hardware-lab5.docx` — проектный расчёт аппаратных требований на один лист.
- `diagrams/utilities-lab5.mdj` — проект StarUML. Исходные диаграммы сохранены,
  новые диаграммы находятся в модели «ЛР-5 — гостевой фронтенд».
- `diagrams/exports/` — изображения диаграмм для РПЗ.

РПЗ использует оформление предоставленного образца: титульный лист с
эмблемой, чёрный Times New Roman, поля и альбомное приложение с методами.
Проверено отображение всех страниц. Инструкции и рамки перед сдачей удалить.
