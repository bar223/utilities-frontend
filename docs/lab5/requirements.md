# Соответствие ЛР-5

Основание: предоставленные README.md (React), README (1).md (общий курс),
лекции 8 и 9. Состояние на 10.11.2026.

| Требование | Реализация |
|---|---|
| Отдельный репозиторий и тематическая ветка | utilities-frontend, lab5-react-spa |
| React + TypeScript, функциональные компоненты | main.tsx, App, страницы |
| React-Bootstrap | Form/Range, Button, Card, Nav, Alert |
| Два гостевых экрана | UtilityTilePage, UtilityFeedPage |
| Тематический фильтр по submit | tariffRate, TariffFilter, App |
| Только mock | UTILITIES_MOCK; нет fetch/axios |
| Фото и видео по умолчанию в проекте | public/media/default-*, запись id=6 |
| 4 пункта меню, доступны 2 | TabBar; Добавление и Вход disabled |
| Без Redux и Context | явные props; нет createContext/useContext/useOutletContext |
| Объяснить все хуки | README, отчёт: state/effect и хуки Router |
| README со страницами, полями и кнопками | README.md |
| Аппаратный расчёт на 1 лист | отдельный DOCX и раздел РПЗ |
| Архитектура, CORS | слои и подготовленный Vite reverse proxy |
| 9 скриншотов | макет отчёта и screenshots.md |
| Текущий РПЗ | отдельный DOCX, ТЗ и таблица API в приложениях |

экранов и mock без бэкенда. Приоритет отдан подробному заданию и порядку показа.
